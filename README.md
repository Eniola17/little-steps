# 🌱 Little Steps

> Big goals. Little steps. Real progress.

Little Steps is a fitness wellness app that turns overwhelming
fitness goals into small, achievable steps.

## 🚀 Try Little Steps

https://little-steps-nmszca5nayqucwjadfgj3c.streamlit.app/

## 🛠️ Built With

- Python
- Streamlit
- Pandas
- JSON
- ChatGPT

## 💡 Inspiration

Fitness goals can feel overwhelming when you don't know where to start.
Little Steps helps users break their goals into practical actions,
set realistic targets, and stay encouraged along the way.

## 🔮 What's Next

Expanding the range of fitness goals and making the recommendations
more personalised.
